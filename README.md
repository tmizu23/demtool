# 基盤地図情報 標高DEMデータ変換ツール - version 1.8.2

http://www.ecoris.co.jp/contents/demtool.html

## お知らせ
JGD2024は2026年4月のEPSG Dataset v12.055で正式登録されました。水平座標はJGD2011と数値的に同一のため、本ツールではJGD2011と同じEPSGコード（緯度経度: 6668, 平面直角: 6669-6687, UTM: 6688-6693）に割り当てて処理します。標高値（鉛直基準の差）は画素値の意味として保たれます。

# 更新情報

## v1.8.2 2026/5/16
・JGD2024のEPSG登録（Dataset v12.055, 2026/4）に対応。
　従来のカスタムWKT定義方式を廃止し、JGD2011と同一のEPSGコードで処理するよう簡素化。
　merge.tifの座標値は変更なし。標高値の鉛直基準は入力GMLの測地系に従う。
・Mark-of-the-Web（Zone.Identifier）の自動解除処理を起動スクリプトに追加。
　ZIP解凍後に各exe/dllを「右クリック→プロパティ→許可する」と手動操作しなくても、
　gdal系exeの起動がハングしないように修正。
